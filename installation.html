安装 Python

💡 2026 年推荐：建议安装 Python 3.14 或 3.13 版本，获得最佳性能和最新特性。Python 3.14 已于 2025 年 10 月发布，带来了显著的性能提升和新特性。

Windows 系统

  1. 访问 Python 官网
  2. 下载最新版本的 Python 安装包（推荐 Python 3.14）
  3. 运行安装程序，勾选 "Add Python to PATH"
  4. 点击 "Install Now" 完成安装

macOS 系统

  1. 使用 Homebrew 安装：brew install python@3.14
  2. 或从 Python 官网下载安装包

Linux 系统

大多数 Linux 系统已预装 Python。如需安装：

sudo apt-get install python3 python3-pip  # Ubuntu/Debian
sudo yum install python3 python3-pip      # CentOS/RHEL

使用 pyenv 管理多版本（推荐）

# 安装 pyenv
curl https://pyenv.run | bash

# 安装指定 Python 版本
pyenv install 3.14.0
pyenv install 3.13.0

# 设置全局版本
pyenv global 3.14.0

# 设置项目局部版本
pyenv local 3.13.0

验证安装

在终端或命令提示符中输入：

python --version
# 或
python3 --version

# 查看 pip 版本
pip --version

升级 pip

python -m pip install --upgrade pip
# 或
pip3 install --upgrade pip

Python 3.14 主要新特性：

  • 🚀 性能提升：CPython 解释器性能优化，启动速度更快
  • 📝 错误消息改进：更清晰、更有针对性的错误提示
  • 🔧 标准库增强：pathlib、asyncio 等模块功能增强
  • 🎯 类型提示改进：更强大的类型检查支持
  • 🗑️ 清理废弃 API：移除已废弃的接口，API 更简洁
