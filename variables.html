变量

变量是存储数据的容器。在 Python 中，不需要声明变量类型：

# 变量赋值
name = "张三"
age = 25
height = 1.75
is_student = True

# 打印变量
print(name)      # 输出: 张三
print(age)       # 输出: 25
print(height)    # 输出: 1.75
print(is_student) # 输出: True
💡 提示：变量名可以包含字母、数字和下划线，但不能以数字开头。
