函数

函数是 Python 中的核心概念，掌握函数式编程能大幅提升代码质量。

函数定义与调用

def greet(name: str) -> str:
    """带类型提示的函数"""
    return f"Hello, {name}!"

# 调用
result = greet("Python")
print(result)  # Hello, Python!

参数类型全解

# 位置参数 vs 关键字参数
def f(a, b, c=10): pass
f(1, 2)           # 位置
f(a=1, b=2)       # 关键字
f(1, b=2)         # 混合

# *args **kwargs - 可变参数
def sum_all(*args, **kwargs):
    print(args)    # (1, 2, 3) 元组
    print(kwargs)  # {"x": 1, "y": 2} 字典

sum_all(1, 2, 3, x=1, y=2)

# 仅关键字参数 (Python 3+)
def f(*, key=None):  # 必须用关键字传参
    print(key)
f(key="value")

返回值与多返回值

# 返回多个值 - 实际返回 tuple
def stats(numbers):
    return sum(numbers), len(numbers), sum(numbers)/len(numbers)

total, count, avg = stats([1, 2, 3])

# 提前返回
def find_user(users, id):
    for u in users:
        if u["id"] == id:
            return u
    return None

Lambda 匿名函数

# 单行简单函数
square = lambda x: x ** 2
print(square(5))  # 25

# 配合内置函数
nums = [1, 2, 3, 4, 5]
squares = list(map(lambda x: x**2, nums))
evens = list(filter(lambda x: x%2==0, nums))

# sorted 配合 lambda
users = [{"name": "Bob", "age": 30}, {"name": "Alice", "age": 25}]
sorted_users = sorted(users, key=lambda x: x["age"])

高阶函数

# 函数作为参数
def apply(func, value):
    return func(value)

apply(lambda x: x*2, 5)  # 10

# 函数作为返回值
def multiplier(n):
    return lambda x: x * n

double = multiplier(2)
print(double(5))  # 10

# 偏函数
from functools import partial
def power(base, exp): return base ** exp
square = partial(power, exp=2)
print(square(5))  # 25
💡 技巧：过度使用 lambda 会降低可读性，复杂逻辑还是用 def 定义函数。
